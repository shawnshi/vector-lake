# Pinned direct dependencies for a known-good Vector Lake environment.
#
# This file pins the *direct* dependencies resolved on 2026-09-16
# (Windows, CPython 3.13).  It is a reproducibility aid, not a full
# transitive lock: transitive dependency versions are still decided by the
# resolver, and no artifact hashes are recorded.
#
# To produce a fully locked, hash-verified file once network access to a
# package index is available:
#
#   python -m pip install pip-tools
#   pip-compile --generate-hashes --output-file=requirements.lock.txt requirements.txt
#
# Install the pinned set with:
#
#   python -m pip install -r requirements.lock.txt
#
# Notes
# -----
# * python-louvain is gone: community detection is Leiden via leidenalg+igraph.
# * rjieba wheel used: rjieba-0.2.1-cp38-abi3-win_amd64.whl, carrying jieba-rs
#   0.9.x.  Update this pin and tokenizer.JIEBA_RS_PINNED together when a
#   binding for jieba-rs 0.11 is published.
# * mcp must stay >=2.1: mcp_server.py targets mcp.server.MCPServer. 2.1.0 was
#   verified by a clean `pip install -r requirements.txt` plus a full suite run
#   on Windows/CPython 3.13; 1.x hosts keep working via the FastMCP fallback.
# * mistune must stay >=3.0.1 (3.0.0 breaks renderer='ast').
# * mcp is on the 2.x line: mcp_server.py prefers `mcp.server.MCPServer` and
#   only falls back to the 1.x `fastmcp` name, which 2.x stubs out with a raise.
# * igraph/leidenalg install from cp39/cp38-abi3 wheels; no compiler needed.
