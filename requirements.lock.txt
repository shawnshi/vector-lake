# (Windows, CPython 3.13).  It is a reproducibility aid, not a full
# transitive lock: transitive dependency versions are still decided by the
# resolver, and no artifact hashes are recorded.
#
# To produce a fully locked, hash-verified file once network access to a
# package index is available:
#
#   python -m pip install pip-tools
#   pip-compile --generate-hashes --output-file=requirements.lock.txt requirements.txt
#
# Install the pinned set with:
#
#   python -m pip install -r requirements.lock.txt
#
