## 2025-06-21 - Fix XSS in Graph Topology Visualization
**Vulnerability:** Found both DOM-based XSS (via unescaped `innerHTML` injection of node metadata) and Server-Side XSS (via raw JSON serialization injected into `<script>` tags without escaping HTML entities) in the graph visualization tool.
**Learning:** The architecture dynamically generates an interactive HTML file without using a safe templating engine like Jinja2 with autoescaping. It manually replaces `%%GRAPH_DATA%%` with a JSON dump, and the frontend JS uses `.innerHTML` to render hover metadata, exposing both execution vectors.
**Prevention:** 1) For Python-side JSON injection into HTML contexts, always use `json.dumps(data, ensure_ascii=False).replace('<', r'\u003c').replace('>', r'\u003e').replace('&', r'\u0026')`. 2) For client-side JS rendering, implement a robust `escapeHTML` utility and consistently apply it to all user-controlled data before `.innerHTML` assignment, alongside `encodeURI()` for dynamic anchor tag `href` attributes.
