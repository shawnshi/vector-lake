## 2024-05-24 - [DOM and Server-Side XSS in Topology Graph]
**Vulnerability:** A High severity XSS vulnerability existed where unescaped user-controlled markdown variables (e.g. `node.name`, `node.group`, `node.validity_state`) were dynamically inserted into the DOM via `.innerHTML` in `templates/topology.html`. Additionally, a Server-Side XSS risk existed in `vector_lake/tool_graph.py` where JSON serialized data wasn't safely escaping HTML characters (`<`, `>`, `&`) before string replacement into the `<script>` tag of the topology HTML template.
**Learning:** `json.dumps` does not automatically escape angle brackets, making it dangerous when directly injected into an inline HTML `<script>` block. Furthermore, using string interpolation within `.innerHTML` in frontend templates requires explicit HTML entity encoding for all dynamically injected values to prevent DOM XSS.
**Prevention:** Always use `escapeHTML` on dynamic properties inserted via `.innerHTML` or `.innerText` and explicitly replace `<` and `>` in JSON strings mapped to inline script tags in templates. Always wrap dynamically injected URLs with `encodeURI()`.
