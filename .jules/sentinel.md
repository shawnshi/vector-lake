## 2024-05-10 - DOM XSS in Topology Viewer Template
**Vulnerability:** Found multiple DOM-based Cross-Site Scripting (XSS) vulnerabilities in `templates/topology.html` where node data (e.g., node id, group, name) was unsafely interpolated into innerHTML blocks and onclick handlers.
**Learning:** Due to the template's reliance on client-side rendering with raw graph data, any node data could execute arbitrary JavaScript. This happened because variables were not sanitized before being injected into the DOM.
**Prevention:** Implemented an `escapeHtml` utility and wrapped all variable interpolations inside innerHTML calls. Also updated dynamic inline event handlers (e.g. `onclick`) to use `data-id` attributes (`onclick="selectNode(this.getAttribute('data-id'))" data-id="${escapeHtml(...)}"`) rather than concatenating escaped variables directly into the inline handler, preventing JavaScript syntax errors and retaining robust XSS protection. Always escape dynamic content when manipulating innerHTML or use `textContent`/`innerText`.
