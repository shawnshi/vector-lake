## 2024-05-15 - XSS in HTML Template via JSON Payload
**Vulnerability:** Untrusted node metadata and titles derived from user-controlled Markdown sources were directly injected into an inline `<script>` tag inside `templates/topology.html` using a basic `json.dumps`. The JSON string was placed right before a `</script>` tag. Since standard `json.dumps(ensure_ascii=False)` does not escape `<` or `>` characters, it was possible for malicious values to close the JSON string block prematurely or construct `<script>` payload inside to achieve Server-Side Cross-Site Scripting (XSS).
**Learning:** Even though `json.dumps` safely generates valid JSON, placing that string *inside* an HTML script context opens it up to XSS because the HTML parser resolves `</script>` tags before the JavaScript engine interprets the string.
**Prevention:** When injecting JSON directly into a script tag context, escape dangerous HTML entities (`<`, `>`, `&`) to their Unicode equivalents (`\u003c`, `\u003e`, `\u0026`). In Python, this can be done manually via `.replace()`, provided raw strings or double escapes (`r'\u003c'`) are used to prevent Python evaluating it to the actual characters before output. Alternatively, if available, `json.dumps(..., ensure_ascii=True)` provides basic coverage.
