## 2024-05-31 - Fix DOM XSS in topology viewer via innerHTML
**Vulnerability:** In `templates/topology.html`, untrusted dynamic data (such as `node.name`, `node.id`, `node.group`, and others) was directly interpolated into HTML strings and rendered onto the page via assignments to `.innerHTML`. This allowed any page or claim data containing HTML markup (e.g. `<script>`) to execute arbitrary Javascript (DOM-based XSS).
**Learning:** The use of string template literals combined with `.innerHTML` makes it very easy to accidentally introduce DOM XSS. While properties like `.innerText` and `.textContent` are safe by default, dynamic HTML generation requires explicit escaping.
**Prevention:** Always use a dedicated escaping function (like `escapeHTML`) when interpolating user-controlled or external data into an HTML string destined for `.innerHTML`. Alternatively, use safer DOM manipulation methods such as `document.createElement()` paired with `.textContent` where possible.
