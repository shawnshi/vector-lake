## 2025-01-20 - [Fix Cross-Site Scripting (XSS) in topology.html]
**Vulnerability:** A potential Server-Side XSS vulnerability existed where the dynamically generated JSON graph data injected into `%%GRAPH_DATA%%` in `templates/topology.html` wasn't safely escaped before injection into an inline HTML script tag block.
**Learning:** Even when serializing JSON data for a web context, characters like `<`, `>`, and `&` aren't sanitized by default via Python's `json.dumps`. Without escaping, malicious payloads embedded inside the strings within JSON can bypass script boundaries and potentially execute arbitrary Javascript on the client side when loaded.
**Prevention:** Always escape HTML special characters such as `<`, `>`, and `&` when dynamically generating JSON payloads that will be directly injected into an inline `<script>` tag. When performing replacements in Python to unicode escaped sequences (e.g. `\u003c`), raw strings (like `r'\u003c'`) must be used to prevent prematurely interpreting unicode sequences back into actual unescaped HTML characters.
