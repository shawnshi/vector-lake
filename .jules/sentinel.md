## 2024-05-09 - DOM XSS in Inline Event Handlers Mitigation
**Vulnerability:** User-controlled dynamic strings from node properties (e.g., node IDs, names) were directly interpolated into inline HTML event handlers (e.g. `onclick="selectNode('${targetId}')"`) or written using `.innerHTML`, introducing DOM-based XSS vulnerabilities.
**Learning:** Interpolating escaped strings directly into JavaScript contexts inside HTML attributes can still break syntax or be bypassed. HTML rendering in client-side graphs often lacks automated template sanitization compared to backend frameworks.
**Prevention:** Avoid interpolating variables into inline handlers entirely. Instead, use DOM manipulation (e.g., `document.createElement`), set safe properties like `.textContent`, and store dynamic values using `data-*` attributes (`setAttribute('data-id')`), which can be safely retrieved during event callbacks using `this.getAttribute('data-id')`. Use a robust HTML escaping function for strings that must be inserted as HTML content.
