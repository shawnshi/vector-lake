## 2024-05-18 - [DOM-Based XSS via innerHTML in Static HTML Templates]
**Vulnerability:** Direct interpolation of graph properties (like `node.name`, `node.group`, `color`, `state`) into `innerHTML` strings and inline Javascript event handlers (`onclick="selectNode('${targetId}')"`) within static HTML templates, leading to DOM-based Cross-Site Scripting (XSS).
**Learning:** Static visualizations and graph UI components often load raw data structures and attempt to render them directly as HTML strings for simplicity. Because the node attributes originate from Markdown (which allows unconstrained text) or other dynamic sources, failing to escape them safely allowed attackers to inject `<script>` tags or malicious attributes.
**Prevention:** Always use safe DOM APIs (like `textContent` or `innerText`) for setting text content. If `innerHTML` must be used for constructing nested HTML tags, ensure all dynamically interpolated variables are sanitized through an `escapeHTML` function. Additionally, avoid interpolating variables directly into JS handlers (`onclick`); utilize `data-*` attributes and `getAttribute()` to cleanly separate data and code execution.
