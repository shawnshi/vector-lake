## 2024-05-24 - DOM XSS in Topology Template
**Vulnerability:** Multiple DOM-based Cross-Site Scripting (XSS) vulnerabilities found in `templates/topology.html` where dynamic, user-provided data (e.g., node names, groups, metadata from markdown) was directly interpolated into `innerHTML` strings and inline JavaScript event handlers (e.g., `onclick`).
**Learning:** The UI rendering logic trusted data originating from markdown files without sanitization. Constructing HTML strings with raw user input allows malicious node data to execute arbitrary JavaScript in the user's browser. Escaping contexts matter; variables inserted into HTML context need HTML entity encoding, while variables inserted into JS context (like inline `onclick` attributes) require different escaping or safer patterns.
**Prevention:** Always use an `escapeHTML` function when interpolating dynamic data into `innerHTML`. Better yet, use `.textContent` or `.innerText` where HTML formatting is not required. Avoid interpolating variables directly into inline JavaScript event handlers; instead, pass data securely using `data-*` attributes (e.g., `data-id`) and retrieve it using `this.getAttribute('data-id')` within the handler to prevent syntax breakage and JS injection.
