## 2025-05-11 - [DOM XSS Mitigation in Topology Graph]
**Vulnerability:** DOM-based Cross-Site Scripting (XSS) in `templates/topology.html`. Untrusted graph node data (`node.name`, `node.group`, metadata, source links) was unsafely injected directly into the DOM using string concatenation and `element.innerHTML = ...`. Event handlers (`onclick`) were also vulnerable to injection through unescaped `targetId` strings.
**Learning:** The frontend templates render raw graph JSON data generated dynamically by the backend, meaning any poisoned graph edge/node will automatically execute arbitrary code on the client's browser if the graph UI trusts the JSON content.
**Prevention:** Always use safe DOM rendering techniques such as `document.createElement()` and `element.textContent` instead of `innerHTML`. When HTML injection is unavoidable, strictly apply an HTML entity escaping helper function (`e(str)`) to untrusted strings before interpolation. Avoid interpolating strings into inline event handlers (e.g. `<a onclick="foo('${val}')">`); instead, use event listeners or pass data via `data-*` attributes (`this.getAttribute('data-id')`).
