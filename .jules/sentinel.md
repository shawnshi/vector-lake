## 2024-06-03 - Prevent JSON XSS when directly replacing HTML variables
**Vulnerability:** A vulnerability was found in `vector_lake/tool_graph.py` where JSON serialized data containing unescaped HTML characters (`<`, `>`, `&`) was injected directly into a `<script>` tag in an HTML template (`templates/topology.html`) using simple string replacement (`html.replace("%%GRAPH_DATA%%", json.dumps(...))`).
**Learning:** This approach enables Cross-Site Scripting (XSS) because an attacker can create a graph node with a malicious script (e.g., `</script><script>alert(1)</script>`), which breaks out of the enclosing `<script>` tag when rendered and executes arbitrary JavaScript in the user's browser.
**Prevention:** When substituting stringified JSON into an HTML document inline, ensure that the JSON string escapes `<` and `>` tags appropriately. In Python, this can be done safely with chained replacements: `json.dumps(data).replace('<', r'\u003c').replace('>', r'\u003e').replace('&', r'\u0026')`.
