## 2026-06-19 - Server-Side and DOM XSS in Graph Visualization
**Vulnerability:** Server-Side XSS via unescaped JSON injection in `templates/topology.html` (`%%GRAPH_DATA%%`), and DOM-based XSS via unescaped property interpolation (e.g. `node.name`, `node.group`) into `.innerHTML` assignments in `vector_lake/tool_graph.py` and `templates/topology.html`.
**Learning:** `json.dumps` does not automatically escape characters like `<`, `>`, and `&`, making it unsafe to inject directly into `<script>` tags if the data originates from parsed markdown content. Furthermore, using `.innerHTML` to render raw JSON properties directly bypassing HTML entity escaping introduces severe Client-Side XSS risks.
**Prevention:** Always escape `<` to `\u003c`, `>` to `\u003e`, and `&` to `\u0026` via raw string replacements when injecting JSON into `<script>` tags (`json.dumps(..., ensure_ascii=False).replace(...)`). Use an explicit `escapeHTML()` function for any dynamic data injected via `.innerHTML`, and ensure URLs are sanitized with `encodeURI()` before placing them in `href` attributes.
