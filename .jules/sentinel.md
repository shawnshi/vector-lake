
## 2024-06-19 - Fix Server-Side and DOM-Based XSS in Vector Lake Topology Graph
**Vulnerability:** Both Server-Side XSS (via unescaped `json.dumps` payload inside a `<script>` tag in `vector_lake/tool_graph.py`) and DOM-based XSS (via unsanitized `.innerHTML` and dynamic `href` assignments in `templates/topology.html`) were present in the graph rendering logic. Malicious node or group names could prematurely close the script block or inject arbitrary HTML.
**Learning:** The architecture dynamically interpolates compiled index structures directly into static HTML templates without a web framework to handle escaping natively. Relying solely on `json.dumps` is unsafe when embedding in `<script>` tags, and using `.innerHTML` without an explicit `escapeHTML` utility exposes the UI to DOM-based XSS when rendering user-generated content from Markdown.
**Prevention:** Always post-process `json.dumps` with explicit Unicode escaping for `<`, `>`, and `&` (`replace('<', r'\u003c')`, etc.) when injecting JSON into HTML script blocks. Use a robust `escapeHTML` function for all dynamic content interpolated into `.innerHTML` strings, and ensure dynamic URLs are passed through `encodeURI()`.
