## 2024-05-15 - [XSS vulnerabilities in vector_lake dashboard]
**Vulnerability:** Server-Side XSS in `vector_lake/tool_graph.py` via unescaped JSON injection and DOM-based XSS in `templates/topology.html` via `.innerHTML`.
**Learning:** Python's `json.dumps` does not automatically escape `<` and `>` into unicode by default (unless ensure_ascii=False is used along with manual string replacement). Injecting JSON directly into `<script>` context enables breaking out of the script tag if a node name contains `</script>`. Furthermore, using `.innerHTML` to render HTML templates in Javascript leaves the app vulnerable to DOM-based XSS if the data originates from unescaped markdown metadata.
**Prevention:** Always escape HTML characters (`<`, `>`, `&`) using `str.replace` with raw strings (e.g. `r'\u003c'`) when serializing Python dictionaries to JSON for direct script injection. In HTML files, use `escapeHTML` for dynamic variable injection in `.innerHTML` and use `encodeURI` for URL paths.
