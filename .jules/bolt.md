## 2024-05-20 - PyYAML C-Loader/C-Dumper Optimization
**Learning:** PyYAML provides C-based Loaders and Dumpers (`CSafeLoader`, `CDumper`) that interface with LibYAML, offering up to 4x-8x speedups over pure Python implementations (`SafeLoader`, `Dumper`) for YAML parsing and serialization. However, they are not available on all platforms and require fallback mechanisms. Given that Vector Lake heavily parses and serializes frontmatter in Markdown files, using the pure python implementation was an architecture bottleneck for indexing.
**Action:** Always wrap `CSafeLoader` and `CDumper` imports in a `try...except ImportError` block falling back to the pure Python `SafeLoader`/`Dumper`. Use `yaml.load(data, Loader=SafeLoader)` instead of `yaml.safe_load(data)` to pass the dynamically chosen loader. Apply this pattern to any high-throughput YAML processing to ensure performance speedups without risking portability issues.
