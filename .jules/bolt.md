## 2025-02-28 - PyYAML C-Extensions for High-Volume Parsing
**Learning:** The Vector Lake architecture inherently relies on thousands of YAML frontmatter blocks embedded across `.md` files. Standard Python `yaml.safe_load` and `yaml.dump` calls create a substantial processing bottleneck during recursive index builds and lint passes due to PyYAML's pure-Python fallback. By manually binding `CSafeLoader` and `CDumper`, execution time per file drops by ~6x. This optimization is critical due to the O(n) scaling nature of knowledge graphs.
**Action:** When working in knowledge graph or flat-file environments backed by Markdown+YAML, always ensure `yaml.load(..., Loader=SafeLoader)` uses `CSafeLoader` as a fallback from pure Python to drastically reduce parsing overhead without changing semantics.
