## 2024-06-11 - YAML Parsing bottleneck in markdown-heavy architectures
**Learning:** In architectures like Vector Lake that rely heavily on YAML frontmatter embedded within thousands of markdown files, standard `yaml.safe_load` and `yaml.dump` can become a critical bottleneck (O(n) where n is file count times file reads/writes). Pure Python pyyaml parsing is notoriously slow.
**Action:** Use conditional imports to attempt loading the C-extensions `CSafeLoader` and `CDumper` (LibYAML) which drop-in replace the pure Python versions but run 5x-8x faster. Provide a pure-python fallback for environments without compiler support. Create internal helper functions (`load_yaml`, `dump_yaml`) to ensure this optimization is easily reusable across the codebase without redundant try-except blocks.
