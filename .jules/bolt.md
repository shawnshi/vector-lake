## 2024-06-10 - [Speed up YAML parsing with LibYAML]
**Learning:** In Vector Lake, Markdown files with YAML frontmatter are extremely common and parsed frequently during index generation and validation scans. The pure Python `yaml.safe_load` and `yaml.dump` are significantly slower than their C-based equivalents (`CSafeLoader`, `CDumper`). Relying on the C-based extensions when available results in massive speedups (~7x faster parsing, ~4x faster serialization) for a critical performance path without changing behavior.
**Action:** When working with YAML parsing/dumping in Python, attempt to import and use the LibYAML-based `CSafeLoader` and `CDumper` from `yaml`. Provide a fallback to the pure Python `SafeLoader` and `Dumper` for environments where the C extensions are unavailable to avoid portability issues.
