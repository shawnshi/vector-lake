## 2024-06-22 - Optimize YAML Parsing & Dumping
**Learning:** Vector Lake's architecture relies heavily on Markdown files where metadata is encoded as YAML frontmatter on every single file, making YAML parsing and dumping a critical performance path during index generation and validation scans. `yaml.safe_load` and `yaml.dump` are pure Python by default in `pyyaml` and are quite slow compared to their C-based `CSafeLoader` and `CSafeDumper` counterparts.
**Action:** Create a `yaml_utils.py` with `load_yaml` and `dump_yaml` helper functions that fall back gracefully between the C implementation and pure Python if LibYAML is missing. Replace slow `yaml.safe_load` and `yaml.dump` with these wrappers in core processing paths like `indexer.py`, `wiki_utils.py`, `skeleton_parser.py`, and common scripts. Ensure to keep `import yaml` for exception handling like `except yaml.YAMLError:` where necessary.
## 2026-06-23 - Optimize O(N²) Edge Calculation in Indexer
**Learning:** In Vector Lake's index generation, calculating weighted edges operates in O(N^2) complexity because every node must be compared to every other node. Previously, `set()` conversions were instantiated on every inner loop pass, and expensive set intersections (`&`) were executed unconditionally. This resulted in significant CPU overhead during indexing runs.
**Action:** Lift static invariants out of the nested loop. Pre-compute node properties (like `links` and `sources`) into O(1) dictionaries before the loop begins. Additionally, when evaluating logical conditionals (like `A or B or C`) where the components are computationally heavy, rewrite them as nested `if not A:` short-circuits so that expensive operations (like `B` and `C`) are completely skipped if `A` is true.
## 2026-06-24 - Optimize O(N²) Python Object Creation
**Learning:** In Vector Lake's indexer, calculating weighted edges operates in O(N^2) complexity. To maintain performance, avoid redundant conversions or operations inside inner loops by passing down pre-computed collections (like sets), hoisting inner function definitions to the module level, and using module-level `frozenset`s instead of tuples for O(1) lookups.
**Action:** When working in inner O(N^2) loops in Python, push sets out of the function entirely and pass them in as default-`None` arguments (to maintain backwards-compatibility). Convert O(N) `in tuple` lookups to O(1) `in frozenset` lookups. Avoid allocating empty dictionaries in fallback `.get()` handlers.
