## 2024-06-22 - Optimize YAML Parsing & Dumping
**Learning:** Vector Lake's architecture relies heavily on Markdown files where metadata is encoded as YAML frontmatter on every single file, making YAML parsing and dumping a critical performance path during index generation and validation scans. `yaml.safe_load` and `yaml.dump` are pure Python by default in `pyyaml` and are quite slow compared to their C-based `CSafeLoader` and `CSafeDumper` counterparts.
**Action:** Create a `yaml_utils.py` with `load_yaml` and `dump_yaml` helper functions that fall back gracefully between the C implementation and pure Python if LibYAML is missing. Replace slow `yaml.safe_load` and `yaml.dump` with these wrappers in core processing paths like `indexer.py`, `wiki_utils.py`, `skeleton_parser.py`, and common scripts. Ensure to keep `import yaml` for exception handling like `except yaml.YAMLError:` where necessary.
