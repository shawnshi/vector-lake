# Entity: OpenAI

(Top Section: Compiled Truth / 编译事实)
**OpenAI** 是全球 AI 演进的顶层设计方，其战略重心已从通用人工智能（AGI）转向超级人工智能（[[Concept_ASI]]）的物理重构与安全对冲。

### 1. 核心战略锚点
- **超级智能引力源**: 发起关于 [[Concept_能力悬垂]] 的全球警示，主导 ASI 时代的系统安全议程。
- **基础设施推动者**: 倡导 [[Concept_算力平权]] (Universal Basic Compute)，试图通过无限算力供应破解“赛博封建主义”。
- **防御机制重塑**: 提出 [[Concept_涌现式防御]] 模型，放弃静态对齐，转向基于算力耗散的动态免疫网络[^1]。

### 2. 致命脆弱点与商业阻力
- **监管捕获风险**: 其提出的“中间态监管机构”被质疑可能沦为科技寡头的合规白手套。
- **认知阶级撕裂**: 算力平权愿景与由于执行归零被无限放大的“认知差距”之间存在天然张力。
