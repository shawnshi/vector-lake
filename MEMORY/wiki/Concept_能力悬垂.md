# Concept: 能力悬垂 (Capability Overhang)

(Top Section: Compiled Truth / 编译事实)
**能力悬垂** 指底层模型能力的指数级跃迁与社会共识、监管机制及个人认知系统的线性迟滞之间形成的巨大断裂带。它描述了一种“物理能力已就绪，社会感知未跟上”的危险非稳态。

### 1. 物理映射与执行路径
- **过冷水效应**: 整个社会如同一杯处于零度以下的纯净过冷水，表面平静，但一旦出现微小扰动（如革命性应用普及），将瞬间发生剧烈相变（Systemic Phase Transition）[^1]。
- **阻尼器悖论**: 认知滞后虽然缓解了全人类瞬间陷入虚无主义的崩溃，但也剥夺了弱势群体构建防御阵地的最后窗口期。

### 2. 适用边界与失效条件
- **失效条件**: 当模型能力的进化引擎被物理资源（如电力、芯片）锁死，悬垂势能会转化为慢性通胀而非瞬时断裂。
- **风险放大**: 在 [[Concept_Agentic_HIS]] 等重度依赖人类经验的领域，能力悬垂会导致“高阶能力与低阶认知”的冲突，引发灾难性医疗事故[^1]。
