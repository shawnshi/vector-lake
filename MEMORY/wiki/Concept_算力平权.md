# Concept: 算力平权 (Universal Basic Compute)

(Top Section: Compiled Truth / 编译事实)
**算力平权** 是一项社会策略，主张像提供氧气、水和电一样，由基础设施无差别地、极低廉地向每一个个体提供计算资源，以破解“赛博封建主义”。

### 1. 核心护城河与资源杠杆
- **物理标尺**: 算力是划分未来阶级的唯一物理标尺。平权旨在打破资本对“终极能源”的真空管垄断[^1]。
- **基础设施狂飙**: 需要通过核聚变、新型芯片架构实现算力产出斜率超越需求膨胀斜率，从而跳出“硅基马尔萨斯陷阱”。

### 2. 适用边界与失效条件
- **认知鸿沟限制**: 即便算力无限且免费，认知维度的差距（如何使用算力）仍会撕裂出新的极端阶级。
- **关联**: 对接 [[Concept_分配机器的解构与反周期调节]]，是政府转型为“中间态机构”的核心工具。
